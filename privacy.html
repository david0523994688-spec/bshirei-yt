Privacy Policy

What the app does

"Bshirei David Avdecha – personal upload tool" uses the YouTube Data API to access only the owner's own YouTube channels (David Bashiri), in order to upload and manage his own videos (titles, descriptions, thumbnails, playlists).

Data collection

No data from any other user is collected, stored, sold or shared. The tool is used solely by its owner.

Token storage

The owner's OAuth access/refresh tokens are stored privately on his own server only and are never transferred to any third party.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
